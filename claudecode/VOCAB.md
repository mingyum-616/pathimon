# VOCAB.md — 패시몬 공식 어휘집 (v2)

> **이 파일이 유일한 정본이다.** 노트에 쓰는 모든 타입·태그·상태이상·기술타입·처치계열은 여기 있는 값만 사용한다.
> 목록에 없는 값이 필요하면 **노트에서 임시 대체하지 말고 이 파일에 먼저 추가**한다.
> (v1에서 "경련은 공식 목록에 없어 신경 이상으로 표현했다" 같은 즉흥 처리가 어색함의 최대 원인이었다.)

---

## 1. 타입 (6종 고정)

병원체 분류 6개와 1:1 대응한다. **이 6개 외의 값은 타입에 쓸 수 없다.**

| 타입 | 설명 | 중간범위 해당 |
|---|---|---|
| 세균 | 원핵생물 | 1~30, 55~59 (35종) |
| 바이러스 | 비세포성 | 31 (1종) |
| 기생충 | 연충·다세포 기생생물 | 32~54 (23종) |
| 진균 | 곰팡이·효모 | 없음 (기말범위) |
| 원생동물 | 단세포 진핵 기생생물 | 없음 (기말범위) |
| 프리온 | 감염성 단백질 | 없음 (기말범위 / **전설 취급**, §7 참조) |

> **v1 마이그레이션:** `타입: 선충 / 흡충 / 조충` → `타입: 기생충` + `structure: 선충 / 흡충 / 조충`

---

## 2. 태그 (4축)

전투 상성 판정의 **유일한 근거**다. 적의 기술은 태그를 보고 특효/반감/무효를 결정한다(→ `MATCHUP.md`).

```
태그:
- structure:   (구조·형태) 최대 2개
- location:    (기생 위치) 최대 2개
- evasion:     (회피·생존 구조) 최대 2개  ← v2 신설, 구 '방어특성' 흡수
- pathway:     (감염 경로) 최대 3개
```

**개수 상한은 가독성 규칙이다.** 시험에 나오는 것만 남기고 나머지는 `학습포인트`로 보낸다.

### 2-1. structure (구조)

| 값 | 적용 |
|---|---|
| 그람양성 | 두꺼운 펩티도글리칸 |
| 그람음성 | 외막 보유 |
| 항산성 | 마이코박테리움, 노카르디아(부분) |
| 세포벽없음 | 마이코플라스마, 유레아플라스마 |
| 아포형성 | Bacillus, Clostridium |
| 나선균 | 스피로헤타 등 |
| 외피보유 | enveloped virus |
| 외피없음 | non-enveloped virus |
| 레트로바이러스 | 역전사 보유 |
| DNA바이러스 / RNA바이러스 | 유전체 종류 |
| 선충 / 흡충 / 조충 | 기생충 하위 분류 |
| 원충 | 원생동물 전반 (v2.4 신설) |
| 편모충 / 섬모충 / 포자충 | 원충 하위 분류 — 운동기관 기준 (54강) |
| 영양형 / 포낭형 | 원충 생활사 단계 (54강) |
| 유충 / 성충 / 충란 | 생활사 단계(진화 시스템과 연동) |
| 효모형 / 균사형 / 이형성 | 진균(기말범위) |

### 2-2. location (위치)

| 값 | 적용 |
|---|---|
| 세포외 | 대부분의 화농균 |
| 세포내 | 결핵균, 리스테리아, 살모넬라, 바이러스 |
| 세포내외겸용 | 조건부 세포내 기생 |
| 점막표면 | 정착만 하고 침습 안 함(가드네렐라 등) |
| 혈류 | 균혈증·주혈흡충 |
| 장관 / 담관 / 폐 / 뇌 / 눈 / 근육 / 림프계 / 요로 / 간 / 피하 | 장기 특이 |

### 2-3. evasion (회피·생존) — **v2 신설**

**학습 축이다. 배율에는 걸리지 않는다.** 플레이어는 병원체 편에서 치료를 맞는 쪽이고, 이 태그는
"이 병원체가 어떤 식으로 치료를 빠져나가는가"를 **노트 본문과 프로필로 읽히게** 한다.
적 공격의 배율은 `대처법:`·`증상/태그:` 적중으로 ×4 / ×2 / ×1만 정해진다(→ `MATCHUP.md` §1 v2.2).
**반감·무효는 없다** — 그러니 여기 값을 고른다고 전투가 유리해지지는 않는다. 강의 근거대로 정확히 적는 것이 전부다.

| 값 | 의미 | 대표 |
|---|---|---|
| 협막 | 다당류 협막으로 식세포 회피 | 폐렴구균, 클렙시엘라, 탄저 |
| 아포 | 환경 저항성 휴면체 | 탄저, 파상풍, 보툴리눔, 디피실레 |
| 세포벽없음 | 세포벽 표적 약물의 표적 자체가 없음 | 마이코플라스마, 유레아플라스마 |
| 항산성 | 왁스질 세포벽, 약물 침투 차단 | 결핵균, 노카르디아 |
| 세포내은신 | 식포 내 생존, 세포 간 직접 전파 | 리스테리아, 살모넬라, 시겔라 |
| 잠복 | 유전체 통합·휴면, 약물 도달 불가 | HIV, 결핵(잠복) |
| 항원변이 | 표면 항원 지속 변경 | HIV |
| 생물막 | 균집단 매트릭스 형성 | 가드네렐라, 도관 감염 |
| 낭종 | 피낭·낭미충 형성, 사멸 시 염증 폭발 | 유구조충, 폐흡충, 선모충 |
| 유충이행 | **유충**이 조직을 이동하며 정착 회피 | 아니사키스, 개회충, 스파르가눔 |
| 조직이행 | **성충**이 조직을 이동하며 정착 회피 | 로아사상충, 메디나충 |
| 항원위장 | 숙주 항원·MHC를 흉내내거나 표면에서 지우기 | 수두대상포진, 거대세포 (MHC 하향조절) |
| 자가감염 | 체내에서 스스로 증식 사이클 | 분선충, 요충, 장모세선충 |
| 내성효소 | 항생제 분해효소 생성 | CRE, MRSA |
| 보체회피 | 보체 활성화·MAC 형성을 차단 | 화농성연쇄상구균(M단백), 수막알균 |
| 위산저항 | 위산을 견디고 소량으로 감염 성립 | 시겔라, EHEC, 폴리오바이러스 |
| 환경저항 | 숙주 밖에서 건조·소독에 견디는 구조 | 노로바이러스, 아데노바이러스, 진균 분생포자 |
| 철획득 | 시데로포어로 숙주의 철 격리(영양면역)를 우회 | 녹농균, 클렙시엘라, 요로병원성 대장균 |
| 없음 | 특기할 회피 구조 없음 | 세레우스 등 |

> **`환경저항` 중복 금지.** `structure`에 `외피없음` 또는 `아포형성`이 있으면 `evasion: 환경저항`을 같이 쓰지 않는다.
> 둘 다 `환경차단`을 반감시키므로 §1 곱연산으로 ×0.25가 되어 밸런스가 깨진다. `환경저항`은 structure로 잡히지 않는 경우(진균 분생포자, 원충 포낭) 전용이다.

### 2-4. pathway (경로)

호흡기 / 소화기 / 상처 / 피부접촉 / 성접촉 / 혈액 / 수직감염 / 매개곤충 / 토양접촉 / 오염수 /
해산물생식 / 민물고기생식 / 갑각류생식 / 육류섭취 / 채소섭취 / 분변경구 / 의료관련

> **`민물고기생식` vs `갑각류생식`.** 흡충 각론에서 **제2중간숙주가 어류냐 갑각류냐가 곧 종 감별**이다
> (어류 → 간흡충·요코가와흡충 / **참게·가재 → 폐흡충**). 같은 값으로 뭉개면 그 감별이 태그에서 사라진다.

### 2-5. 구 `방어특성` → evasion 정규화 표

v1 노트 129개가 쓰던 `방어특성:` 값 73종을 정리한 결과다(→ `drafts/AUDIT_v2.md` §7).
**왼쪽 표기를 노트에 그대로 쓰지 않는다.** 오른쪽 정식 값으로 바꾼다.

| v1 표기 | → evasion 정식 값 |
|---|---|
| 바이오필름 | 생물막 |
| 세포내생존 / 세포내침입 / 대식세포생존 / 식포융합차단 / 포식소체성숙차단 | 세포내은신 |
| 항산성막 | 항산성 |
| 산저항 / 산저항성 | 위산저항 (**항산성과 다르다** — 왁스질 세포벽이 아니라 위산 내성이다) |
| 무세포벽 | 세포벽없음 |
| 과점액협막 / F1협막 / Vi협막 | 협막 |
| 근육낭종 / 낭미충 / 조직낭종 / 폐낭종 | 낭종 |
| 잠복감염 / 신경절잠복 / B세포잠복 / 혈관잠복 / 적혈구잠복 / 림프잠복 / 지속감염 / 저강도지속감염 / 만성화 | 잠복 |
| 스파이크변이 / 형태전환 | 항원변이 |
| 내성 / 반코마이신내성 | 내성효소 |
| M단백 / 면역회피 | 보체회피 |
| 비외피안정성 / 이중캡시드 / 포자분산 / 환경저항성 | 환경저항 (위 중복 금지 규칙 확인) |

### 2-6. evasion이 아닌 것 — 이관표

회피·생존 구조가 아니어서 상성 판정에 걸리지 않는 값이다. **evasion에 넣지 않는다.**

| v1 `방어특성` 값 | 이관처 |
|---|---|
| 담관정착 / 눈기생 / 간이행 / 간실질이행 / 림프정착 / 신경이행 / 신경축삭이동 / 조직침습 | `태그.location` (§2-2) |
| 피하이동 / 조직이행 | 이동 자체가 **정착 회피**로 이어지는 경우만 evasion으로 올린다 — **유충**이면 `유충이행`, **성충**이면 `조직이행`(§2-3). 그 외에는 `태그.location` |
| 부착선모 / 섬모부착 / 장점막부착 / 장점막고정 / 두관극부착 | 회피가 아니라 정착 기전 → **준비기 기술** 또는 `학습포인트` |
| 피하결절 | `태그.location: 피하` (회선사상충) |
| 위막장벽 | 회피 구조가 아니라 병인 산물(디프테리아 위막) → **공격기 기술** 또는 `학습포인트` |
| 유레아제 | 위산 중화 기전(철 획득도, 위산저항 태그도 아니다) → `학습포인트` |
| 면역기억소거 | 홍역의 immune amnesia. 실재하지만 **백신·항체가 홍역에 매우 유효**하므로 상성으로 만들면 현실을 왜곡한다 → `학습포인트` |
| 흡혈 / 편절분리 / 편모운동 / 접촉전파 | 병인·생활사 → `학습포인트` |
| 저온증식 / 염분선호 / 미세호기성 / 정상균총 / 대형저항 | 상성 판정에 안 걸림 → **폐기** |

## 3. 상태이상 (공식 목록)

**표기법:** `상태이상명(n)` — n은 **지속 턴 수**. 생략 시 기본 2턴.
`상태이상명(∞)` — 해제되기 전까지 영구 지속(만성·잠복 표현).

| 상태이상 | 효과 | 대표 |
|---|---|---|
| 발열 | 턴당 슬립 데미지(최대 HP 2%) | 전신 감염 |
| 출혈 | 턴당 슬립 데미지(현재 HP 2%) | 출혈열·장출혈 |
| 빈혈 | 턴당 슬립 데미지(최대 HP 1%) | 구충·HUS |
| 배설 이상 | 턴당 슬립 데미지 + 탈수 유발 | 설사·이질 |
| 기침 | 공격할 때마다 현재 HP 2% 피해 | 폐 감염 |
| 괴사 | 최대 HP 상한 감소(비가역) | 조직 파괴 |
| 피로 | 공격 -5% | 만성·소모성 |
| 통증 | 방어 -5% | 조직 침습 |
| 혈압 이상 | 방어 -7.5%, 상태이상 피해 +5% | 패혈증·쇼크 |
| 시력 이상 | 명중 -12.5% | 안구 침범 |
| 청력 이상 | 명중 -7.5% | 내이 침범, 이독성 약제 |
| 마비 | 행동 불가 확률 5% | 신경독소 |
| 구토 | 행동 실패 확률 4% | 식중독 |
| 가려움 | 행동 실패 확률 2.5% | 알레르기·피부 |
| 신경 이상 | 혼란 확률 +5%p | 신경 침범 |
| 탈수 | HP 회복량 -12.5% | 설사 질환 |
| 황달 | HP 회복량 -7.5% | 담도 폐쇄 |
| 호흡 곤란 | 받는 직접 피해 +5%, 즉사 확률 0.5% | 폐렴·기도 폐쇄 |
| 부종 | 모든 상태이상 확률 +1%p | 염증·림프 폐쇄 |
| 면역 이상 | 4스택마다 방어특성 1개 무력화 | 면역결핍 |

> **계열은 여섯이다.** 도트(발열·출혈·빈혈·배설 이상·기침) / 최대 HP(괴사) / 능력치(피로·통증·혈압 이상) /
> 명중(시력·청력) / 행동(마비·구토·가려움·신경 이상) / 회복(탈수·황달) / 메타(호흡 곤란·부종·면역 이상).
> 새 상태이상을 넣을 때는 **어느 계열에 들어가는지 먼저 정한다.** 계열이 겹치면 수치로 차등한다.
>
> **도트를 제외한 수치는 모두 낮게 잡혀 있다.** 상태이상은 스택으로 쌓이고 기술마다 하나씩 붙으므로,
> 한 개짜리 수치가 커 보이지 않아도 전투 중반이면 여러 개가 겹친다. 밸런스 조정은 실제 전투 로그를 보고 한다.

> **금지:** 위 목록에 없는 상태이상을 노트에서 새로 만들지 않는다.
> `경련` → `신경 이상`, `암` → `괴사`처럼 대체할 경우 **노트가 아니라 이 파일에 매핑을 등록**한다.

### 3-1. 공식 매핑 (별칭 → 정식 명칭)

| 쓰고 싶은 말 | 정식 상태이상 |
|---|---|
| 경련 / 발작 | 신경 이상 |
| 강직성 마비 | 마비 + 신경 이상 |
| 이완성 마비 | 마비 |
| 악성 변화 / 암 | 괴사(∞) |
| 복통 | 통증 |

## 7. 프리온 특례 (전설 취급)

프리온은 다른 5타입과 규칙이 다르다. **기말범위 진입 시 적용.**

- **타입:** 프리온 / **structure:** 변형단백질 / **location:** 뇌 / **evasion:** 잠복(∞)
- **스탯 상한 면제:** 일반 상한(§STATS)을 초과할 수 있다. 단 **공격은 낮고 HP·방어가 극단적으로 높은** 형태를 기본으로 한다(느리지만 막을 수 없음).
- **치료 상성:** 항생제·항바이러스제·항기생충제 **전 계열 무효**. `환경차단`(멸균)조차 반감. → *유효한 처치가 존재하지 않는다*는 사실 자체가 학습 포인트.
- **진화 없음**, 포획 방식도 별도 설계 대상.
- **상태이상:** 신경 이상(∞), 괴사(∞) 중심.
