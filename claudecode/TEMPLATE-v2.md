## 필드별 작성 규칙

### 이름
기존 작명 유지. 변경 제안은 노트에 반영하기 전 반드시 확인받는다.

### 학명
`한글명(영문 학명)` 형식. 예: `탄저균(Bacillus anthracis)`

### 타입
**`VOCAB.md` §1의 6개 중 하나만.** 세균 / 진균 / 원생동물 / 기생충 / 바이러스 / 프리온
- 선충·흡충·조충은 타입이 아니라 `structure`로 내린다.

### 태그
- 값은 **`VOCAB.md` §2에 있는 것만** 사용한다.
- 개수 상한: structure 2, location 2, evasion 2, pathway 3.
- **상한은 가독성 규칙이다.** 넘칠 것 같으면 시험에 나오는 것만 남기고 나머지는 `학습포인트`로 보낸다.
- `evasion`이 정말 없으면 `없음`을 쓴다. 억지로 만들지 않는다.

### 학습포인트
- **`L1`부터 번호 부여**, 랜덤 출제 시 이 번호로 뽑는다.
- 카테고리 4종: `[감별점]` `[기전]` `[치료]` `[생활사·역학]`
- **개수:** 최소 4개, 권장 5~8개. 카테고리당 최소 1개 이상 포함.
- **한 항목 = 한 문장.** 시험에 나올 수 있는 형태로 쓴다.
- **게임 내부 사정을 쓰지 않는다.** (v1 오류: "급성 복통은 공식 상태이상 통증으로 표현한다" ← 이런 문장은 `작업메모`로)

예시:
```
학습포인트:
- L1 [감별점] 피부탄저의 가피는 검고 통증이 없다. 통증 없는 궤양이 다른 피부감염과의 감별점이다.
- L2 [기전] PA(protective antigen)는 EF와 LF를 세포 안으로 들여보내는 운반체 역할을 한다.
- L3 [기전] EF는 adenylate cyclase로 작동해 cAMP를 올려 부종을 만든다.
- L4 [기전] LF는 MAPKK를 절단해 세포를 사멸시킨다.
- L5 [치료] 균을 죽여도 이미 방출된 독소는 남으므로 항독소를 함께 쓴다.
- L6 [생활사·역학] 아포 형태로 토양에서 장기간 생존하며, 흡입탄저는 드물지만 치명률이 가장 높다.
```

### 포획 OX
야생 포획 시 내는 OX 퀴즈. **`학습포인트`에서 파생한다.** 형식: `문장 | O/X | 근거 L#`.
- **개수:** 4~5문항.
- **거짓(X) 문항은 그 노트의 특정 `L#`을 모순시켜 만든다** (예: L1 "그람음성" → "그람양성 (X)"). 그 병원체 기준으로 거짓이 확정된다. **다른 병원체 문장을 끌어오지 않는다** — 공통 병독인자·치료제·같은 속 문장은 대상에게도 참이라 오정보가 되기 때문이다.
- **≥1문항은 `[치료]` 근거** (직접처치 OX). 오답 처치는 *그럴듯하지만 틀린 계열* 약으로(너무 쉽지 않게).
- **≥1 거짓(X), ≥1 참(O)** — O/X 혼합.
- `근거 L#`은 답한 뒤 해설로 보여주는 학습포인트다(따로 저작 안 함, 재사용). 반드시 학습포인트에 존재.

예시:
```
포획 OX:
- 탄저균의 가피는 통증이 심하다. | X | L1
- PA는 EF와 LF를 세포 안으로 들여보내는 운반체다. | O | L2
- 탄저는 균을 죽이면 항독소 없이도 낫는다. | X | L5
- 탄저는 시프로플록사신 같은 항생제와 항독소를 함께 쓴다. | O | L5
```

### 대처법
각 줄을 4요소로 구조화한다. **`계열`은 `VOCAB.md` §6의 값만** 사용한다.
```
- 1차: 시프로플록사신 | 계열: 핵산합성억제 | 기전: DNA gyrase 억제 | 표적 태그: 그람양성
- 보조: 탄저 항독소 | 계열: 항독소 | 기전: PA 중화로 EF·LF 진입 차단 | 표적 태그: 독소
- 무효/금기: 없음 | 사유: —
```
- `무효/금기` 줄은 **반드시 채운다.** 없으면 `없음`. (EHEC의 항생제 금기 같은 항목이 여기 들어간다)
- `표적 태그`는 `MATCHUP.md` 상성표와 어긋나면 안 된다.

### 증상/태그
검색·필터용 키워드 나열. 상태이상은 `VOCAB.md` §3의 정식 명칭만 쓴다.

### 능력치
`STATS.md` 밴드로 판정 후 수치를 적고, **밴드와 근거를 주석으로 남긴다.**
```
- 공격: 95   # 밴드: 5   근거: 치사 독소, 흡입탄저 치명률 높음
- 방어: 45   # 밴드: 2   근거: 항생제 감수성 양호, 1차 약제로 치료됨
- HP: 40     # 밴드: 2   근거: 급성 경과, 만성화·보균 없음
```

### 진화
기생충이 아니면 `- 패턴: 해당없음`만 적고 나머지는 비운다.
```
진화:
- 패턴: C (분기 진화)
- 전 단계: 낭미충
- 다음 단계: [장 성충형] / [낭미충형]
- 태그 변화: 낭미충형은 location 장관→뇌·눈, evasion 없음→낭종
- 비고: 낭미충 섭취와 충란 섭취의 결과가 다르다는 것이 최우선 학습 목표
```

### 기술
- **슬롯:** 준비기 1 + 공격기 1~2 + 전용기 1. 전용기는 4번 슬롯 고정.
- `타입`은 `VOCAB.md` §5의 값만.
- `위력`은 `STATS.md` §6 밴드 안에서. **다단계 기술에 합계 상한은 없다** — 각 단계가 실제로 병을 얼마나 일으키는지로 정한다(`STATS.md` §6-1).
- `상태이상`은 `VOCAB.md` §3 목록만. 지속 턴은 `(n)` 표기, 생략 시 2턴.
- `효과`는 `VOCAB.md` §4 목록만.
- **모든 필드를 빈칸으로 남기지 않는다.** 해당 없으면 `—`를 적는다. (v1 오류: 세레우스 전용기 위력 공란, `effect` 필드 자체 누락)

**`description` vs `learnText` 구분:**

| 필드 | 대상 | 내용 |
|---|---|---|
| `description` | 전투 로그 | `{name}`을 써서 지금 무슨 일이 일어났는지. 짧게. |
| `learnText` | 학습 팝업 | **의학적 사실만.** 게임 용어·개발 메모 금지. |

```
description: {name}이 EF(edema factor)로 cAMP를 증가시켜 부종을 만들었다.
learnText: EF는 adenylate cyclase로 작동해 세포 내 cAMP를 올린다.
```

### 작업메모
개발용 기록. **학습자에게 노출되지 않는 유일한 블록**이므로, 판단 근거·대체 처리·미해결 사항을 전부 여기에 적는다.
```
작업메모:
- 후보 번호: 1
- 출처 강의: 03, 05
- 검증 상태: 강의 대조 완료 / 미완료 / 부분
- 판단 기록: 탄저 독소 위력 200 → 밴드 상한 초과로 3단계 누적(0/40/95)으로 변경
```

## 작성 순서 (권장)

1. `학습포인트` 먼저 쓴다 → **무엇을 가르칠지 정하고 나서 기술을 만든다.** (역순으로 하면 기술이 특성을 반영 못 하는 v1 문제가 재발한다)
2. `태그` 확정 → 상성이 결정된다
3. `대처법` 확정 → 적 기술이 결정된다
4. `능력치` 밴드 판정
5. `기술` 설계 — 각 기술이 `학습포인트` 중 어느 번호를 가르치는지 대응시킨다
6. `이미지`, `작업메모`
