# 패시몬 노트 v2 키트

패시몬(감염·면역 학습 게임) 노트 규격 v2. **6개 파일이 한 세트다. 전부 같은 폴더에 두고 Claude Code에서 함께 읽혀야 한다.**

## 파일 구성

| 파일 | 역할 | 언제 보나 |
|---|---|---|
| `README.md` | 진입점 (이 파일) | 처음 |
| `VOCAB.md` | **어휘 정본** — 타입·태그·상태이상·기술타입·처치계열 | 값을 고를 때마다 |
| `MATCHUP.md` | **상성 정본** — 태그 × 처치계열 판정표, 특수 규칙 | 태그·대처법 정할 때 |
| `STATS.md` | 능력치 3축 루브릭, 위력 밴드, 59종 앵커, 진화 4패턴 | 수치 정할 때 |
| `TEMPLATE-v2.md` | 노트 스키마 + 필드별 작성 규칙 | 노트 쓸 때 |
| `WORKFLOW.md` | 강의 대조 절차, QA 체크리스트, Claude Code 프롬프트 | 작업 시작·마무리 |
| `EXAMPLE-탄저록스.md` | 골드 스탠다드 (v1→v2 마이그레이션 완성본) | 막힐 때 참고 |

## 시작하기

```
1. WORKFLOW.md §4-3 일괄 감사 프롬프트를 먼저 돌린다   ← VOCAB에 뭘 더 넣어야 할지 파악
2. STATS.md §5 앵커 13종부터 재작성
3. 묶음 단위로 진행 (대장균 6 → 살모넬라 4 → 시겔라 4 → …)
4. 종당 WORKFLOW.md §2 QA 체크리스트 통과
```

## v1 대비 핵심 변경 4가지

1. **`방어특성` 필드 폐기 → `태그.evasion`으로 흡수.** 태그만 상성 판정에 쓰이는데 방어특성은 판정 밖에 있어 정보만 늘리고 있었다. evasion으로 내리면 회피 구조가 그대로 치료 상성이 된다(세포벽없음 → β-lactam 무효 등).
2. **`메모` 폐기 → `학습포인트` 신설.** 번호(L1, L2…)와 카테고리([감별점]/[기전]/[치료]/[생활사·역학])를 붙여 랜덤 출제에 쓴다. **기술보다 먼저 확정한다.**
3. **능력치 3축 재정의.** 공격=병독성·급성 중증도 / 방어=치료 저항성 / HP=지속성·만성도. 셋이 다른 것을 재므로 스탯 자체가 정보가 된다. 탄저 100/100/100 앵커는 폐기.
4. **`설계검토` 블록 제거 → `WORKFLOW.md` 체크리스트로 이관.** v1에선 검토 결과가 아니라 "재검토한다"는 지시문이 59개 노트에 복붙된 채 방치돼 있었다.

## 반드시 지킬 원칙

- **어휘는 `VOCAB.md`에만 존재한다.** 없는 값이 필요하면 노트에서 임시 대체하지 말고 `VOCAB.md`를 먼저 고친다. (v1 어색함의 최대 원인이 노트별 즉흥 처리였다)
- **규칙은 노트에 복사하지 않는다.** 상성은 `MATCHUP.md`, 밴드는 `STATS.md`에만. 노트가 규칙을 품으면 59개가 반드시 어긋난다.
- **강의가 정본이다.** 일반 의학지식과 어긋나면 강의를 따르고 차이를 `작업메모`에 남긴다. 강의에 없는 내용은 넣지 않는다.
- **`learnText`에 게임 용어를 쓰지 않는다.** 개발 메모는 전부 `작업메모`로.
