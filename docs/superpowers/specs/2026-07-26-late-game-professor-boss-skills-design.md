# 70~100층 교수 보스 전용기 설계

## 목표

70·80·90·100층에 무작위 배치되는 교수 보스 네 명에게 전용 이미지, 대사, 고정 방어특성, 100층 전용기를 부여한다. 전용기는 해당 교수가 100층에 배치되었을 때만 조우 대사 직후 한 번 발동한다.

## 공통 조우 흐름

100층 교수 보스는 다음 순서로 진행한다.

1. 조우 대사를 한 문장씩 출력한다.
2. 전용기 대사를 출력한다.
3. `{보스 이름}은 {전용기 이름}을 사용했다!`를 출력한다.
4. 전용기 효과를 한 번 적용한 뒤 전투를 시작한다.

70·80·90층에서는 조우 대사만 출력하고 전용기는 발동하지 않는다. 모든 대사는 기존 보스 인트로의 타이핑 효과와 입력 진행 방식을 그대로 사용한다.

## 데이터 구조

기존 `BossData`와 `RuntimeMonster`의 `finalBossSkill`을 다음 네 종류로 확장한다.

- `parasitization`: Prof. P의 기생충화
- `seal`: Prof. S의 봉인
- `keen_eye`: Prof. K의 예민한 눈초리
- `nk_activation`: Prof. W의 NK 활성화

공통 필드는 다음과 같다.

- `finalBossSkillName`: 전용기 표시 이름
- `finalBossSkillDialogue`: 전용기 사용 직전 대사 목록
- `finalBossSkillApplied`: 100층에서 이미 적용했는지 여부

지속효과에 필요한 런타임 상태는 보스에게 저장한다. 보스 ID를 전투 처리 여러 곳에서 직접 비교하지 않고 `finalBossSkill`과 전용 상태를 기준으로 판정한다.

## 교수별 설정

### 기생충학 교수 Prof. P

- 이미지: `images/trainers/boss/prof_p.png`
- 고정 방어특성: `parasite_master`
- 표시명: `기생충 마스터`
- 조우 대사: `기생충은 재미있었나요..?`, `하하`
- 2페이즈 대사: `음.. 아침에 먹은 연어 칼국수가..`
- 전용기: `기생충화`
- 전용기 대사: `최후의 기생충학은... 나 자신이 기생충이 되는 것!`

기생충화가 활성화된 Prof. P가 처음 쓰러지면 승리 처리하지 않고 충란 상태로 전환한다.

- 이름 뒤에 `-충란`을 붙인다.
- 2턴 동안 공격하지 않는다.
- 공격과 상태이상 피해를 받아도 HP가 감소하지 않는다.
- 상태이상 부여와 스택 누적은 정상적으로 허용한다.
- 충란 상태는 한 번만 발생한다.
- 2턴이 끝나면 이름 뒤를 `-성충`으로 바꾼다.
- 공격력을 80으로 설정한다.
- 괴사 등 최대 체력 상한 감소를 반영한 현재 유효 최대 체력까지 회복한다.

### 미생물학 교수 Prof. S

- 이미지: `images/trainers/boss/prof_s.png`
- 조우 대사: `새로운 인형이니..?`
- 2페이즈 대사: `One minute...`
- 전용기: `봉인`
- 전용기 대사: `새로운 인형이네..?`

기존 봉인 효과를 유지한다. 전투 가능한 패시몬 한 마리를 무작위로 골라 능력치는 유지하지만 기술을 사용할 수 없는 봉인 인형으로 만든다.

### 약리학 교수 Prof. K

- 이미지: `images/trainers/glacia.png`
- 기본 공격력: 40
- 고정 방어특성: `mycology_master`, `protozoology_master`
- 표시명: `진균 마스터`, `원생동물 마스터`
- 조우 대사: `안녕하세요 패시몬 여러분?`
- 2페이즈 대사: `학습태도가 참 좋네요.. 어렵게 해볼까요?`
- 전용기: `예민한 눈초리`
- 전용기 대사: `여기서는 다 보인답니다.`

예민한 눈초리가 활성화된 동안 플레이어가 자발적으로 패시몬을 교체할 때마다 Prof. K의 공격력이 1랭크 상승한다.

- 중첩 가능하다.
- 최초 선출에는 적용하지 않는다.
- 패시몬 사망이나 봉인으로 인한 강제 교체에는 적용하지 않는다.

### 병리학 교수 Prof. W

- 이미지: `images/trainers/boss/ghetsis.png`
- 이름: `병리학 교수 Prof. W`
- 학명성 설명: `병리학 교수 (Professor of Pathology)`
- 고정 방어특성: `virology_master`
- 표시명: `바이러스 마스터`
- 조우 대사: `목이 아프군.. 긴 말 않겠다. 사라져라.`
- 2페이즈 대사: `음..`
- 전용기: `NK 활성화`
- 전용기 대사: `.....!`

NK 활성화가 적용된 동안 매 상태이상 처리 페이즈에 현재 선출 패시몬이 최대 체력의 10% 피해를 받는다.

- 피해는 현재 선출에게만 적용한다.
- 교체하면 다음 상태이상 페이즈부터 새 선출이 피해를 받는다.
- 현재 선출의 상태 UI에 `NK`를 표시한다.
- 일반 상태이상과 구분되는 전투 지속효과로 취급하며 스택 수는 표시하지 않는다.

## 방어특성 명칭

기존 방어특성 ID와 판정 규칙은 유지하고 표시명만 다음과 같이 통일한다.

- `parasite_master`: 기생충 마스터
- `virology_master`: 바이러스 마스터
- `mycology_master`: 진균 마스터
- `protozoology_master`: 원생동물 마스터

## 판정 순서

전투 라운드 종료 시 다음 순서로 판정한다.

1. 양측 공격과 일반 상태이상 처리를 완료한다.
2. NK 활성화 피해를 현재 선출에게 적용한다.
3. Prof. P의 HP가 0 이하이면 첫 사망을 충란 전환으로 대체한다.
4. 충란 턴을 진행하고 2턴 완료 시 성충으로 변환한다.
5. 최종 사망, 패시몬 쓰러짐, 2페이즈 진입 여부를 판정한다.

충란 상태에서는 Prof. P의 공격 계획을 비우고 적 행동 로그에 충란이 공격하지 않는다는 문구를 출력한다.

## 검증

- 네 교수의 이미지, 이름, 대사, 고정 방어특성, 전용기 데이터가 올바른지 확인한다.
- 100층에서만 `조우 대사 → 전용기 대사 → 사용 메시지 → 효과 적용` 순서가 성립하는지 확인한다.
- Prof. P가 첫 사망에 충란으로 전환하고, 2턴간 HP 피해를 받지 않으며, 상태이상은 누적되고, 이후 성충으로 한 번만 부활하는지 확인한다.
- Prof. W가 상태이상 페이즈마다 현재 선출에게 최대 체력 10% 피해를 주고 `NK`가 표시되는지 확인한다.
- Prof. K가 자발적 교체에만 공격 +1을 얻고 강제 교체에는 얻지 않는지 확인한다.
- Prof. S의 기존 봉인 효과가 유지되는지 확인한다.
- 전체 데이터 무결성 테스트, 전투 테스트, UI 테스트와 배포 빌드를 실행한다.
