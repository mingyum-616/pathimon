# 첫 플레이 가독성 감사 (2026-07-25)

대상: https://mushpiba.github.io/pathimon/ (배포본)
환경: Chrome, 창 1440×900 → 캔버스 1024×576 논리 해상도가 1136×639로 스케일(×1.11)
플레이 범위: 타이틀 → 스토리 3컷 → 면책 → 전투 안내 → 모드 선택 → 스타터 선택 → 1층 포획(OX 퀴즈) → 2층 → 도감/상성표/패시몬/안내 모달

> ⚠️ 배포본이 작업 트리보다 오래됐다. 예: `gameGuideUi.ts`에는 섹션 5개 + 페이지네이션이 있는데 배포본은 4개 + 페이지 표시 없음. 아래 지적 중 일부는 로컬에서 이미 고쳐졌을 수 있으니 **재배포 후 재확인** 필요.

## 2. 근거 (코드 위치)

### P0-1 · 모바일 오버레이가 데스크톱에 노출
`app/src/scenes/BattleScene.ts:2578`

```ts
private drawMobileOverlay(): void {
  const depth = 900;                       // 거의 최상단
  ...
  this.drawActionOverlayButton(896, 452, 48, 'A', ...);
  this.drawActionOverlayButton(802, 510, 44, 'B', ...);
}
```

`mobileControlOverlayInteractive()` (`app/src/ui/battleUi.ts:458`)는 **상호작용만** 막고, 그리기는 무조건 실행된다. 결과:

- A 원(896,452 r48) → `캡슐` 버튼 라벨 위를 덮음
- B 원(802,510 r44) → `도감`/`패시몬` 버튼 사이를 덮음
- D-패드 사각형(118,500) + `↑↓←→` 라벨 → 좌측 대사/설명 텍스트 위를 덮음
- 도감 화면에서는 종족명·능력치 줄을 덮음

### P0-2 · 버튼 좌표 충돌
- `그만둔다`: `BattleScene.ts:1771` → x 846–988, y 510–550
- `처음으로`: `battleUi.ts:448` → x 900–1008, y 538–566
- 겹침 영역 x 900–988 × y 538–550

### P0-3 · 층 배지 z-순서
`BattleScene.ts:646`의 층 배지가 파티 뷰에서도 같은 좌표에 그려져 1번 슬롯 카드와 겹친다.

### P1-4 · 포커스/호버/선택 시각 신호 동일
`app/src/scenes/ModeSelectScene.ts:87`

```ts
rect.setStrokeStyle(focused ? 4 : 2, selected || focused ? ACTIVE_LINE : COLORS.line);
```

`ModeSelectScene.ts:160`

```ts
rect.on('pointerover', () => rect.setFillStyle(SELECTED_FILL));   // 호버 채움 == 선택 채움
```

구분 요소는 테두리 굵기 2px 차이와 10~11px `선택됨` 칩뿐. 실제로 첫 진입 시 `학습모드`가 선택된 것처럼 보였고, `게임 시작`을 눌러도 반응이 없었다(실제로는 미선택 상태).

### P1-5 · 타이포 스케일
`app/src/ui/draw.ts:38`

```ts
const minSize = options.minSize ?? Math.max(9, size - 4);
```

`BattleScene.ts` 실사용 크기: 8, 9, 10, 11, 12, 13, 14, 15, 17, 18, 19, 20, 21, 22, 23, 24, 25, 30, 31, 34, 36 (21단계).
`minSize: 8`을 넘기는 호출이 다수(`:1029`, `:922`, `:924`, `:981`, `:983`). 캔버스가 1024 논리폭이므로 브라우저 창이 1024px 이하면 스케일 ≤1.0 → 한글 8~10px은 판독 불가.

### P1-6 · 테두리 색 단일화
`app/src/game/constants.ts`

```ts
line: 0xd64541,   // 빨강 — drawPanel 기본 stroke + 대부분 버튼 stroke
```

`draw.ts:78`의 `drawPanel`이 모든 패널에 같은 빨강 2px을 준다. 정보 패널, 액션 버튼, 경고, 모달이 전부 같은 시각 무게.

### P1-7 · 도감 밀집도
`BattleScene.ts:1061` / `:1068` / `:1078`

```ts
addBoxLabel(this, 238, y, `${row.name} · ${multiplierLabel}`, { size: 13, minSize: 10 ... });
addBoxLabel(this, 452, y + 1, `${row.type} · 위력 ${row.power} · 명중 ${row.accuracy}`, { size: 11 ... });
addBoxLabel(this, 258, y + 17, description, { size: 10 ... });
```

열 머리글 없음, 4개 정보군이 한 행에 겹쳐 있고 설명 줄이 10px. 마지막 행이 패널 하단에서 잘린다.

## 3. 수정 설계

### Phase 0 — 겹침 버그 (반나절, 코드 ~30줄)

**0-1. 오버레이 그리기 자체를 게이팅**

`BattleScene.ts:2578` 최상단에 조기 반환 추가:

```ts
private drawMobileOverlay(): void {
  if (!this.mobileControlOverlayInteractive()) return;
  ...
}
```

- 검증: 데스크톱에서 A/B/D-패드 미표시. 기존 `battleUi.test.ts`의 `mobileControlOverlayInteractive` 테스트 유지 + 씬 레벨 테스트 1개 추가(터치 아님 → 오버레이 오브젝트 0개).
- 부수효과: `처음으로` 버튼도 터치 전용이 된다 → 데스크톱 이탈 경로 필요. `그만둔다` 옆 또는 우상단 아이콘 메뉴에 `처음으로` 항목 추가.

**0-2. 터치에서의 `그만둔다`/`처음으로` 충돌 해소**

`mobileHomeButtonLayout()`을 `{ x: 8, y: 8, width: 108, height: 28 }`로 이동(층 배지 반대편 상단). 액션 버튼 영역과 완전 분리.

**0-3. 층 배지 억제**

`drawFloorBadge` 호출을 전투 필드 뷰에서만 하도록. 파티/스테이터스 뷰 조기 반환 경로(`BattleScene.ts:353`, `:363`)에서는 그리지 않는다.

### Phase 1 — 디자인 토큰 (1~2일)

**1-1. 타이포 스케일 고정**

새 파일 `app/src/ui/typography.ts`:

```ts
export const TEXT = {
  display: 32,   // 씬 타이틀
  title: 24,     // 패널 제목, 대사 헤드라인
  heading: 20,   // 섹션 제목
  body: 16,      // 본문 · 버튼 라벨
  label: 14,     // 보조 라벨 · 표 셀
  caption: 12,   // 최소 단위 (하한)
} as const;

export const MIN_TEXT_SIZE = TEXT.caption;
```

`draw.ts:38` 하한 상향:

```ts
const minSize = Math.max(MIN_TEXT_SIZE, options.minSize ?? size - 4);
```

기존 8~11px 호출부는 `caption`(12) 또는 `label`(14)로 올리고, 넘치는 곳은 **글자를 줄이지 말고 정보를 줄인다**(설명 줄은 선택 시에만 노출).

**1-2. 색 역할 분리**

`constants.ts`에 추가:

```ts
border:       0x4a4258,  // 기본 패널 테두리 (중립)
borderStrong: 0x8a7fa6,  // 강조 패널
focus:        0x72d6ff,  // 포커스 링 (시안)
selected:     0x42d66b,  // 선택 확정 (초록)
danger:       0xd64541,  // 경고 전용 — 기존 line
```

- `drawPanel`은 `border` 사용, `line`(빨강)은 경고·페널티 전용으로 축소.
- 텍스트 muted 최소 알파 0.85. 0.3 알파 라벨(`BattleScene.ts:2606`)은 오버레이 제거로 함께 사라짐.

**1-3. 선택 상태 3단 분리** (`ModeSelectScene`, `StarterSelectScene`, 파티 카드 공통)

| 상태 | 테두리 | 채움 | 부가 |
|---|---|---|---|
| 기본 | `border` 2px | `panelDark` | — |
| 포커스/호버 | `focus` 3px 점선 아님, 바깥 글로우 | 기본 유지 | — |
| 선택됨 | `selected` 4px | 밝은 채움 | 좌상단 `✓ 선택됨` 칩 `label`(14px), 배경 있는 필 형태 |

핵심: **포커스는 채움을 바꾸지 않는다**. 채움 변화 = 선택 확정 신호로만 쓴다.

### Phase 2 — 화면별 재배치

**2-1. 도감 / 상성표** (`BattleScene.ts:1024`–`1165`)
- 열 머리글 행 추가: `처치 | 계통 | 위력 | 명중 | 배율`
- 배율(`×4`/`×2`/`×1`)을 이름 뒤 텍스트가 아니라 **색 칩**으로 우측 고정 열에 배치(×4 빨강, ×2 주황, ×1 회색)
- 행 4개 고정 + `◀ 1/2 ▶` 페이저. 설명 서브라인은 커서가 놓인 행에만 `label`(14px)로 노출
- 좌측 요약(`도감 / 이름 / 타입 / HP·공격·방어`)을 `label` 14px 이상으로

**2-2. 전투 안내** (`GameGuideScene`)
- 배포본 4섹션 → 작업 트리의 2페이지 구성으로 재배포하고, **페이지 인디케이터를 상단 헤더에** 붙인다(현 위치는 좌하단 16px)
- `×4 / ×2 / ×1`을 문장에서 빼내 상단 칩 3개로: `직접 처치 ×4` `간접 처치 ×2` `무관 ×1`
- 용어 각주 1줄 추가: "처치 = 약·치료법, 예고 = 적이 다음 턴에 쓸 처치"
- 본문 14px → `body`(16px), 섹션당 3줄 → 2줄로 압축

**2-3. 스토리** (`StoryScene`)
- 배경 패널을 캔버스 전체(1024×576)로 확장 → 상하 검은 띠 제거
- 삽화 최대 높이를 텍스트 박스 상단까지로 클램프 → 상단 잘림 제거
- 텍스트 박스를 배경 경계에 걸치지 않게 하단 고정, `▶ 계속` 마커 표시
- `1 / 3` 인디케이터를 `caption` → `label`로

**2-4. 면책조항** (`DisclaimerScene`)
- 하단에 `확인하고 계속` 버튼 명시(현재 어포던스 없음)
- 문단 간격 통일(현재 3·4번째 문단만 붙어 있음)

**2-5. 스타터 선택** (`StarterSelectScene`)
- 상단 빈 패널 제거 또는 "선택한 패시몬 요약" 이동
- `이 파티로 시작`을 하단 패널 안으로 넣고, 미선택 시 disabled 시각(채도↓ + `캡슐을 먼저 고르세요`)
- 캡슐 선택 시 **해당 스프라이트에 선택 링 + `✓`** 표시(현재는 우측 텍스트만 변함)
- `선택한 패시몬 0/1` → `함께 시작할 패시몬 1마리를 고르세요`

**2-6. 캡슐 메뉴** (`BattleScene.ts:994`–`1020`)
- `x∞` → 무한이면 수량 열 자체를 숨기고 유한할 때만 `×3` 표기
- 대상 계열과 일치하는 캡슐 행에 `focus` 테두리 + `계열 일치` 칩
- 메뉴 패널이 플레이어 HP 패널을 덮지 않도록 y 시작점 상향 또는 HP 패널 임시 페이드

**2-7. OX 퀴즈** (`BattleScene.ts:735`–`750`)
- 페널티 문구를 O/X 버튼 **바로 위**로 이동, `label`(14px), 대상 명시: `오답 시 <내 패시몬> 최대 체력 20% 피해`
- `핵심 문장` 라벨은 12px muted 유지하되 알파 0.85

**2-8. 포획 결과** (`BattleScene.ts:2464`–`2480`)
- `파티 2/6 · 계열 2종`을 본문 문단에서 분리해 우상단 상태 줄로

### Phase 3 — 첫 플레이 온보딩 (선택)
- 1층 첫 턴에 액션 4개에 대한 1줄 툴팁(지나간다/캡슐/도감/패시몬)
- 용어 사전 모달(`처치`, `예고`, `계열`, `전용기`, `정비구역`) — 우상단 아이콘 메뉴에 편입
- 우상단 아이콘 2개에 라벨/툴팁(`소리`, `안내`)
